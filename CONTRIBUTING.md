# Contributing

Run the checks in README before proposing a change. Include a failing scenario
for behavior changes, and explain the operational tradeoff. Never commit real
credentials, incident data, database files, or private traces. Use synthetic
fixtures. Keep compatibility and known limitations explicit.

This is an AI-assisted personal engineering project. It does not represent
production employment, real customer traffic, or independently audited security.
The useful evidence is the runnable code, tests, and recorded experiments.
